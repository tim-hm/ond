## Cross-Cutting Concerns

The product changed faster than its explanatory surfaces. Subscription naming, authentication, journey storage, catalogue ownership, CI, logging categories, and the audit skill itself all describe earlier implementations. The documentation findings are separate symptoms of one missing enforcement seam; remediation therefore ends with a mechanical observability-registry check and one documentation reconciliation after code movement settles.

The assistant remains the most concentrated backend surface. Removing its unused explanation RPC must precede splitting tool dispatch, while the stream deadline and Bedrock parser hardening belong in that later extraction. Doing those in the opposite order would preserve dead contract surface inside the new modules.

Several Swift findings share a boundary problem rather than a visual one. StoreKit, HealthKit, reference refreshes, and coach proposals turn framework or wire failures into plausible local states. Their fixes keep graceful UI fallbacks but make invalid values unrepresentable and leave a diagnostic at the boundary.

The previous audit's two critical risks are closed. Plus entitlement now bounds access to the paid model, and the catalogue cache keeps assistant concurrency within the ten-connection pool. The persistent-session migration deliberately supersedes idle expiry; nonce-bound Apple authorisation is the compensating improvement, not a return to expiring device sessions.

- **Issue:** Neither Apple request supplies a nonce and the verifier deliberately ignores the claim. A captured live token can mint a persistent credential for the token owner's identity.
- **Impact:** A short-lived token replay can become account access lasting until sign-out or deletion.
- **Action:** Add caller-and-purpose-bound, single-use, five-minute server challenges and consume them atomically before sign-in or erasure.

### [SEC-002] The voice API key reaches every mise task and Docker build

- **Severity:** Warning
- **Location:** `.mise.toml:90-112`; `.dockerignore`; `Dockerfile:18-32`; `crates/toolkit/src/voice.rs:459-462`
- **Issue:** The ignored `.env` currently contains `ELEVENLABS_API_KEY`, is globally imported by mise, and is not excluded from `COPY . .`.
- **Impact:** Tasks, build scripts, proc macros, and local image layers can read a billable credential.
- **Action:** Move the key to macOS Keychain, exclude secret patterns from build context, add `.p8` ignores, verify the new path, then rotate the old key.

### [SEC-003] Cloud-init executes a mutable remote installer as root

- **Severity:** Warning
- **Location:** `infra/cloud-init.yaml:39-54`
- **Issue:** First boot pipes `tailscale.com/install.sh` directly to a root shell.
- **Impact:** Origin or release-pipeline compromise gains root on every new production host.
- **Action:** Verify the vendor signing key/repository and install an explicitly pinned package version.

#### Security suggestions

### [SEC-004] Apple identity tokens lack a semantic size ceiling

- **Severity:** Suggestion
- **Location:** `account/handlers/grpc.rs:39-95`; `account/service.rs:31-125`; `account/verifier/apple.rs:229-243`
- **Issue:** Account tokens can consume the full 256 KiB gRPC limit before base64, JSON, key lookup, and RSA verification.
- **Impact:** Anonymous callers can force substantially more work than a legitimate Apple token needs.
- **Action:** Reject identity tokens above 8 KiB before verification on sign-in and deletion.

### [SEC-005] Bedrock streams have no absolute lifetime

- **Severity:** Suggestion
- **Location:** `assistant/model/bedrock/client.rs:198-233`; `events.rs:83-114`
- **Issue:** Inter-frame stall protection does not stop a provider that emits within each idle window forever.
- **Impact:** Paid calls can retain relay and provider resources indefinitely.
- **Action:** Add one absolute deadline independent of activity and test expiry, completion, idle failure, and cancellation.

### [SEC-006] Security and deployment executables float on `latest`

- **Severity:** Suggestion
- **Location:** `.mise.toml:7-14,47-54,87-88`
- **Issue:** Cargo-binstall, cargo-audit, osv-scanner, and OpenTofu can change without a repository diff.
- **Impact:** Tool compromise or drift can execute before advisory checks or with production credentials.
- **Action:** Pin reviewed versions and bump them deliberately.
